PREPROCESSING04

Preprocessing Design

Numerical pipeline

1Median imputationrobust fallback for missing numeric values
2Scalingputs numerical variables on a comparable scale
3Feature selectionkeeps informative transformed features

Categorical pipeline

1Most-frequent imputationsafe fallback for unseen missing values
2One-hot encodingappropriate for nominal categories
3ColumnTransformerkeeps both branches synchronized
Key principle: preprocessing is fitted inside the ML workflow — not on the full dataset before the split.
